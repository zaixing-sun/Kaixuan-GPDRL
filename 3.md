\section{Related Work}
\label{Sec: related work}

\subsection{Dynamic Workflow Scheduling in Cloud--Edge Computing}

Dynamic workflow scheduling in Cloud--Edge computing has been studied under
deadline, cost, energy, and utilization objectives. Manual rules often
use task ranks, sub-deadlines, resource reuse, incremental costs, or
non-dominated candidate construction to guide task sequencing and resource
allocation \cite{ohds,rmes,li2024,lou2023,lwff}. These rules provide explicit
scheduling logic. However, their performance depends on expert knowledge in
selecting and combining task, workflow, and resource attributes. When the
execution environment, resource model, workload pattern, or objective
preference changes, the rules may require redesign or careful adjustment.

Learning-based methods learn scheduling policies from data or simulation
experience. Deep reinforcement learning (DRL) and multi-agent DRL have been
used for time--energy scheduling, multi-objective resource allocation, and
collaborative workflow offloading in Cloud--Edge environments
\cite{jayanetti2022,zhang2024,xiao2025}. GATES represents varying ready-task
and virtual-machine sets with heterogeneous-graph attention and learns a direct
allocation policy through an evolution strategy \cite{gates}. Genetic
programming (GP) hyper-heuristics follow a different route by evolving
executable priority rules. CCGP coevolves task-selection, resource-selection,
and container-scaling trees and returns non-dominated scheduling heuristics for
dynamic Cloud--Fog workflows \cite{ccgp}. These studies provide useful methods
for dynamic workflow scheduling, but they either rely on manual rules, learn
direct allocation policies, or deploy fixed evolved rules after training. They
do not address preference-aware online selection among GP-evolved
resource-selection rules.

\subsection{Rule-Assisted Reinforcement Learning for Dynamic Scheduling}

Rule-assisted DRL handles changing candidate sets by using scheduling rules as
actions. At each decision point, the agent selects a rule from a fixed action
set, and the selected rule ranks the current feasible candidates. Liu et al.
used this indirect action representation with manual dispatching rules in
dynamic flexible job shops \cite{liu2022rules}.
The indirect action representation handles changing candidate sets, but the
quality and diversity of a manual rule library still depend on expert design
\cite{xu2024niching}.

Recent studies replace manual rules with evolved rules. Niching and behavior
clustering can preserve different scheduling behaviors, while GP provides
executable routing or sequencing rules for online DRL selection
\cite{xu2024niching,zhao2025tdrl}. The same idea has also been applied to dynamic
Fog workflow scheduling with GP-evolved actions \cite{he2026evolved}. These
studies show the value of using evolved rules as DRL actions. However, they
mainly address single-objective scheduling or fixed objective settings. They do
not construct a compact pool of GP-evolved resource-selection rules for
preference-aware multi-objective workflow scheduling in Cloud--Edge computing.

\subsection{Preference-Aware Multi-Objective Learning}

Multi-objective reinforcement learning (MORL) studies sequential decision
problems with vector-valued outcomes and multiple objective trade-offs
\cite{roijers2013morl,hayes2022morl}. Some methods learn a set of policies or a
continuous Pareto manifold to cover non-dominated behaviors
\cite{vanmoffaert2014pareto,parisi2016pareto}. Other methods incorporate the
requested preference into a shared value function or policy. Dynamic weights,
desired returns, objective-specific action distributions, and
preference-controllable meta-policies are representative ways to adapt one
learned model to different trade-offs
\cite{abels2019morl,yang2019morl,abdolmaleki2020mopo,reymond2022pcn,
yang2025pcrl}.

Pareto set learning provides a related preference-to-solution view. Augmented
Tchebycheff scalarization can train a model that maps preferences to approximate
Pareto solutions \cite{lin2022psl}. PSLGP further embeds preference information
into GP heuristics for multi-objective dynamic scheduling \cite{xu2026pslgp}.
These studies show how preferences can guide a learned policy or heuristic.
However, they do not combine GP-evolved resource-selection rules with
DRL-based online rule selection. The proposed PRS-GPDRL addresses this gap by
building a rule-mode action space from a compact GP resource-selection rule pool and learning
preference-aware selection over this action space.
